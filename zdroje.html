O projektu.

GameZone je školní projekt zaměřený na tvorbu webových stránek pomocí HTML, CSS a umělé inteligence.

Použitá umělá inteligence

OpenAI ChatGPT (model GPT-6) byl použit jako pomocník při plánování struktury webu, generování ukázkového HTML a CSS a vysvětlování commitů. Kód byl upravován a kontrolován během tvorby projektu.

Ukázky použitých promptů

Prompt 1

„Jsem začátečník. Navrhni strukturu minimalistického webu o videohrách se třemi propojenými HTML stránkami.“

Prompt 2

„Napiš externí style.css se světlým designem, kartami a responzivním rozvržením.“

Prompt 3

„Zkontroluj odkazy mezi stránkami a vysvětli, jak postupně ukládat smysluplné commity na GitHubu.“
